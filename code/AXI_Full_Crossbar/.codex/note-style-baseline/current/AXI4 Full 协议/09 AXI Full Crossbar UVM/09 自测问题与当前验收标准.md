# 09 自测问题与当前验收标准

## 自测问题

1. `s_axi_*` 和 `m_axi_*` 分别接谁。
2. 为什么 `s_axi_*` 名字里有 slave，但 UVM master agent 接它。
3. `0x0001_0008` 应该路由到哪个 M 侧端口。
4. `AWLEN=3` 表示几个 W beat。
5. `AWSIZE=2` 表示每个 beat 几个 byte。
6. `WSTRB=4'b0101` 在 32-bit data bus 上会更新哪些 byte lane。
7. 现在这版 master driver 里，`AW` 和 `W` 为什么不再写死先后顺序。
8. slave memory driver 什么时候返回 `B`。
9. monitor 为什么必须等 `VALID && READY`。
10. 一个 4-beat read burst 会产生几个 AR item、几个 R item。
11. 当前 scoreboard 为什么还不能检查数据正确性。
12. 后续如果要查路由，应该比较 S 侧哪个 item 和 M 侧哪个 item。

## 当前阶段验收标准

不用跑 test。你能做到下面这些，就说明这一轮阅读合格：

- 能画出 `2 master -> crossbar -> 3 slave` 数据流
- 能解释 S 侧和 M 侧命名
- 能讲清 AW/W/B 写路径
- 能讲清 AR/R 读路径
- 能说出 wrapper 的三个地址窗口
- 能说出 monitor item 的粒度
- 能列出 scoreboard 下一步四类 checker
