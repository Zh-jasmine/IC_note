# 00 总览与数据流

```mermaid
flowchart LR
    M0["UVM master_agent0"] --> S0["s_axi_if[0]"]
    M1["UVM master_agent1"] --> S1["s_axi_if[1]"]
    S0 --> DUT["axi_crossbar_2m3s_wrapper / axi_crossbar"]
    S1 --> DUT
    DUT --> X0["m_axi_if[0]"]
    DUT --> X1["m_axi_if[1]"]
    DUT --> X2["m_axi_if[2]"]
    X0 --> SL0["UVM slave_agent0 memory"]
    X1 --> SL1["UVM slave_agent1 memory"]
    X2 --> SL2["UVM slave_agent2 memory"]
```



| 名字 | 从 crossbar 角度 | 外部连接对象 | UVM 里由谁驱动 |
| --- | --- | --- | --- |
| `s_axi_*` | crossbar 的 slave interface | 外部 master | UVM master agent |
| `m_axi_*` | crossbar 的 master interface | 外部 slave | UVM slave agent 响应 |

`s_axi_*`是 指DUT 被 master 访问的一侧。
